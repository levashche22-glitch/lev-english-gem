# LEV SHCHERBAKOV gem

A standalone English-learning mini-game website for A2+–B1 learners.

## Included games
- Word Match — vocabulary / meanings
- Pick the Right One — grammar
- Build It — sentence order
- Spell Sprint — spelling + browser text-to-speech

## Run
Open `index.html` in a modern browser.

No server, build system, or backend is required. XP and streak are stored in localStorage.
